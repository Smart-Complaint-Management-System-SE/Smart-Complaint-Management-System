# 1. Sprint 1

## 1.1 Sprint Review

**Sprint Goal:** Improve the usability, accessibility and registration experience of the Smart Complaint Management System.

**Completed User Stories:**

| Issue | Task | Story Points |
|---|---|---:|
| #66 | Home page, navigation bar and user dashboard | 3 |
| #67 | Apply shared stylesheet to user and error pages | 2 |
| #68 | Validate registration input | 2 |

**Total Story Points:** 7

**Sprint Outcome:**
All planned tasks were implemented and completed. The application gained improved navigation, consistent styling and stronger registration input validation.

## 1.2 Sprint Retrospective

**What Went Well**
- Core user-facing improvements were implemented successfully.
- Registration validation improved input reliability.
- Shared styling provided a consistent interface.

**What Could Be Improved**
- UI integration and testing could be started earlier.
- Requirements and acceptance criteria could be reviewed more frequently.

**Action Items**
- Perform integration testing after every major feature.
- Maintain consistent coding and documentation practices.
- Review acceptance criteria before marking issues complete.

**What Went Well**

- Documentation was updated to reflect the implementation.
